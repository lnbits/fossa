# FOSSA - [LNbits](https://lnbits.com) extension

Build your own Bitcoin ATM. FOSSA turns ESP32 hardware with a bill acceptor into a functional lightning ATM that lets people buy bitcoin with cash.

Flash your own device using the web installer at [fossa.lnbits.com](https://fossa.lnbits.com)

## How it works

The extension manages ATM devices that accept fiat currency and dispense bitcoin via lightning. When someone inserts cash, the ATM generates an LNURL-withdraw QR code for the equivalent amount in sats.

## Features

- Bill acceptor integration for ESP32 devices
- Configurable exchange rates and fees
- LNURL-withdraw for easy redemption
- Transaction logging and management

## Usage

1. Enable the extension in LNbits
2. Create a new ATM and configure your rates
3. Flash your ESP32 using the web installer
4. Connect your bill acceptor hardware
5. Users insert cash and scan the QR to receive sats
